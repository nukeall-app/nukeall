## How to Sign

When you open a pull request on GitHub, review this document and leave a comment on the pull request with the exact phrase below:

```text
I have read the CLA Document and I hereby sign the CLA
```

Your GitHub username, user ID, pull request number, and timestamp will be recorded in [`cla-signatures.json`](./cla-signatures.json), so you only need to sign once across all future pull requests.
