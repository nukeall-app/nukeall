# Security Policy

## Reporting a Vulnerability

If you discover a security issue (for example, unintended network egress, XSS in exported HTML reports/archives, or unsafe DOM handling), please report it privately via GitHub Security Advisories or open an issue without attaching sensitive tokens or personal archives.

## Scope & Guarantees

- NukeAll never requests or stores passwords or OAuth client secrets.
- Do not paste session cookies (`ct0`, `auth_token`), `tweets.js` dumps, or personal identifiers into GitHub issues.
